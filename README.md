# Student Performance Prediction using Linear Regression

This project predicts students' Performance Index using a Linear Regression model. It demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), model training, prediction, and evaluation.
The project uses the Student Performance dataset and is implemented using Python and Scikit-learn. The objective is to understand how various academic and lifestyle factors influence student performance and to build a predictive regression model.
The Model evaluation using various metrics and obtain 0.989 as coefficient of determination (R-squared Score). 

## Features

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Categorical feature encoding
- Feature scaling using StandardScaler
- Linear Regression model training
- Prediction on test data
- Model evaluation using MAE, MSE, RMSE, R² Score, and Adjusted R²
- Residual analysis and visualization

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
